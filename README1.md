# Playful Geometric React App

This is a React application showcasing the Playful Geometric design system. The project demonstrates how to use design tokens to create consistent UI components.

## Project Structure

```
├── src/
│   ├── App.jsx          # Main application component
│   ├── main.jsx         # Entry point for the React app
│   └── tokens.js        # Design tokens (colors, spacing, typography, etc.)
├── styles.css           # Global styles and CSS custom properties
├── index.html           # HTML template
└── package.json         # Project dependencies and scripts
```

## Available Scripts

In the project directory, you can run:

### `npm run dev`
Runs the app in development mode with hot reloading.

Builds the app for production to the `dist` folder.

### `npm run preview`
